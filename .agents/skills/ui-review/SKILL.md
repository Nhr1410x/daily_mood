# UI Review Skill

## Goal
Review major screens as a product designer and senior frontend engineer.

## Screens
Home, Exam list, Exam detail, Exam attempt, Result, Question bank, Question editor, Import, Settings.

## Check
- spacing
- typography
- visual hierarchy
- overflow
- responsiveness
- keyboard navigation
- dark mode
- loading states
- empty states
- error states

## Exam Screen
Verify desktop 3-column layout and mobile drawers/sheets for navigation and controls.

## Content
Check long questions, math, code, tables, and images. Nothing should overflow unexpectedly.
