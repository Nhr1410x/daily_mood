# Question Editor Skill

## Goal
Create a flexible educational question editor.

## Features
- question type
- content
- options
- correct answer
- explanation
- difficulty
- subject
- topic
- tags
- points
- media

## UX
Provide edit, preview, validate, save, and cancel.

## Validation
Validation depends on question type. Do not allow saving invalid questions.

## Preview
Preview must use the same rendering system as the real exam screen. Never create a separate fake renderer for preview.
