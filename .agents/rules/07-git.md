# Git Rules

- Keep commits focused and logically grouped.
- Do not commit secrets, credentials, API keys, local databases, build output, or private user data.
- Do not rewrite shared history unless explicitly requested.
- Before a commit, inspect the diff for accidental files and unrelated changes.
- Prefer small, reviewable changes.
- Use descriptive commit messages.
- Do not automatically push to a remote unless explicitly instructed.
